# Formatting comments

Comments support Markdown, a text format that uses punctuation to mark text styles.

| Purpose | What to type |
| --- | --- |
| Bold | `**text**` |
| Italic | `*text*` |
| Inline code | One backtick before and after the code. |
| Code block | Three backticks on a line before and after the code. |
| Quotation | Start the line with `> `. |
| Bullet list | Start each item with `- `. |
| Numbered list | Start each item with a number and a full stop, such as `1. `. |
| Link | `[link text](https://example.com)` |

Type `@` followed by a reader's username to mention them. Recognized mentions link to that reader's profile. Mention notifications are currently unavailable.

Follow the [Content guidelines](./content-guidelines.html) when you take part in a discussion.
